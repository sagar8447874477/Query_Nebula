Visual logic

The final query works because it first detects where a streak breaks, then assigns a streak ID, then counts each streak, and finally takes the maximum.

1

Use LAG()

Look at the previous date for the same device_id.

2

Flag breaks

If previous date is not exactly one day before current date, start a new streak.

3

Build streak_id

Take a running sum of the new-streak flag so consecutive rows share one group ID.

4

Count and max

Count rows per streak_id, then take MAX(streak_length) per device.

Complete SQL query

This is the full query, not the incomplete version. It includes grouping the streaks and finding the maximum streak for every device.

WITH ordered_data AS (
    SELECT
        device_id,
        date,
        LAG(date) OVER (
            PARTITION BY device_id
            ORDER BY date
        ) AS prev_date
    FROM daily_entry
),
flagged AS (
    SELECT
        device_id,
        date,
        CASE
            WHEN prev_date = date - INTERVAL '1 day' THEN 0
            ELSE 1
        END AS new_streak_flag
    FROM ordered_data
),
grouped AS (
    SELECT
        device_id,
        date,
        SUM(new_streak_flag) OVER (
            PARTITION BY device_id
            ORDER BY date
        ) AS streak_id
    FROM flagged
),
streak_lengths AS (
    SELECT
        device_id,
        streak_id,
        COUNT(*) AS streak_length
    FROM grouped
    GROUP BY device_id, streak_id
)
SELECT
    device_id,
    MAX(streak_length) AS max_streak
FROM streak_lengths
GROUP BY device_id
ORDER BY device_id;

Why your earlier query was incomplete

The issue was not only syntax. The bigger problem was that counting rows with diff = 1 does not produce complete streak groups.

1
You detected adjacency, not full streaks.
Rows where the date difference is 1 only tell you that two rows are consecutive. They do not identify where one streak ends and another begins.
2
The first row of each device was missing from the count.
A streak of length 3 has 3 rows but only 2 adjacent pairs, so counting diff = 1 undercounts the true streak length.
3
You needed a streak group identifier.
The running sum of a new-streak flag is what converts row-by-row comparisons into complete streak blocks.
